# ZZLUXORA v9 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build ZZLUXORA v9 — audio-reactive lighting app (PySide6 + librosa + Art-Net) dari nol di `C:\ANDREAS\SCRIPT3`, faithful ke PRD v2.1 (R1 QLC+, R2 skripsi v3, R3 feedback_v2, R4 artnet_v4, R5 GrandMA3).
